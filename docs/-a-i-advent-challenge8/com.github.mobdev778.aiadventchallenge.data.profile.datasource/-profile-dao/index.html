interface ProfileDao

Объект доступа к данным (DAO) для работы с таблицей профилей ProfileEntity.

Предоставляет методы для выполнения операций чтения, записи, обновления и удаления профилей, а также для управления выбором активного профиля. Все операции выполняются асинхронно, а наблюдение за списком профилей реализовано через Flow.
