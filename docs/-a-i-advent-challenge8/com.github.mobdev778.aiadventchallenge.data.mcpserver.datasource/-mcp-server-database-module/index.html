class McpServerDatabaseModule

Модуль внедрения зависимостей для локальной базы данных MCP-серверов.

Предоставляет singleton-зависимости McpServerAppDatabase и McpServerDao через Koin. Настройка хранилища производится в подкаталоге aiadventchallenge системной директории IntelliJ IDEA, что обеспечивает изоляцию данных плагина.
