ChatDao

interface ChatDao

Data Access Object (DAO) для работы с сущностями чатов и сообщений.

Предоставляет асинхронные методы для чтения (в виде Flow) и записи (suspend-функции) данных о чатах и сообщениях в базе данных Room. Поддерживает транзакционную вставку нескольких сообщений и атомарные операции удаления.
