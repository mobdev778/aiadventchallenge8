AgentResponse

data class AgentResponse(val intermediate: Boolean = false, val agent: String, val request: AgentRequest, val message: String, val toolMessages: List<ToolResponse>, val requestTokens: Int, val responseTokens: Int, val taskContext: TaskContext?)

Ответ агента на запрос пользователя (AgentRequest), который может быть как окончательным, так и промежуточным.

Представляет собой результат обработки запроса, включая текстовое сообщение, ответы от использованных инструментов, информацию о потреблённых токенах и обновлённый контекст задачи.
