McpServerListScreenEvent

sealed interface McpServerListScreenEvent

Запечатанный интерфейс, представляющий все возможные события пользовательского взаимодействия на экране списка MCP-серверов. Используется для однонаправленной передачи событий от UI-слоя к ViewModel в архитектуре UDF (Unidirectional Data Flow).

Каждое событие инкапсулирует необходимые данные для обработки конкретного действия пользователя.
