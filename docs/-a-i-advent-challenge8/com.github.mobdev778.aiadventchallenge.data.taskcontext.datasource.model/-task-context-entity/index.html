TaskContextEntity

data class TaskContextEntity(val id: UUID, val task: String, val state: String, val step: Int, val plan: String, val done: String, val current: String)

Сущность базы данных Room, представляющая контекст выполнения задачи.

Хранит полную информацию о текущем состоянии задачи в таблице task_context, включая описание самой задачи, её статус, текущий шаг выполнения, общий план, список завершённых этапов и текущий выполняемый элемент. Используется в слое данных как основная модель для локального хранения и восстановления контекста работы AI-агента.
