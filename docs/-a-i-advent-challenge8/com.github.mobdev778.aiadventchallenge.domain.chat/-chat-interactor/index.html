ChatInteractor

class ChatInteractor(ragChatRepository: RagChatRepository, observeWindowMessagesUseCase: ObserveWindowMessagesUseCase, taskContextRepository: TaskContextRepository, agentOrchestrator: AgentOrchestrator, scope: CoroutineScope)

Центральный интерактор (use‑case) домена чата.

Координирует операции чтения и записи сообщений, управление автоматическим продолжением диалога (автоплэй), взаимодействие с агентами через AgentOrchestrator и синхронизацию контекста задачи (TaskContext).
