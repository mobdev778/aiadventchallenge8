data class ChatMessage(val id: UUID, val chatId: UUID, val parentId: UUID?, val branchB: Boolean, val time: Long, val text: String, val type: MessageType, val tokens: Int, val rank: Int, val toolCallId: String? = null, val name: String? = null)

Модель данных сообщения в чате.

Представляет собой отдельное сообщение внутри определённого чата, хранящее все необходимые метаданные: уникальный идентификатор, текст, временную метку, тип отправителя (пользователь, бот, инструмент, закреплённый факт), информацию о ветвлении диалога и количестве использованных токенов. Каждое сообщение может быть частью древовидной структуры диалога, что позволяет отслеживать альтернативные ветки ответов ассистента.
