RagChatRepository

class RagChatRepository(chatRepository: ChatRepository, documentRepository: RagDocumentRepository, simpleRagSearcher: RagSearcher, json: Json, rankerFactory: RankerFactory, ragRussianFilter: RagRussianFilter)

Репозиторий чата с интеграцией RAG (Retrieval-Augmented Generation).

Связывает управление чатами и сообщениями с RAG-хранилищем документов и фрагментов. Каждое сообщение чата преобразуется в векторное представление и сохраняется в виде RagDocumentChunk, что позволяет выполнять семантический поиск по истории диалогов. При создании чата автоматически генерируется соответствующий RagDocument.
