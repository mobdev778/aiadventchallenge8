@Composable
fun rememberAppRouter(initial: Screen = Screen.ChatList): AppRouter

Создаёт и запоминает экземпляр AppRouter на всё время жизни композиции.

Используйте эту функцию на верхнем уровне вашей Compose-иерархии для инициализации навигатора с заданным начальным экраном initial. Возвращаемый объект передаётся в AppRouterContent для отображения контента.
