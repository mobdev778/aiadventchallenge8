AppRouter

class AppRouter(initial: Screen = Screen.ChatList)

Маршрутизатор экранов приложения.

Управляет текущим состоянием навигации, храня текущий экран в виде Screen. Предоставляет потокобезопасное (благодаря Compose mutableStateOf) чтение и запись через свойство screen. Все методы-переходы (open*) изменяют текущее состояние, что приводит к перекомпозиции дерева, использующего AppRouterContent.

Экземпляр обычно создаётся через rememberAppRouter и передаётся как параметр в корневую композицию.
