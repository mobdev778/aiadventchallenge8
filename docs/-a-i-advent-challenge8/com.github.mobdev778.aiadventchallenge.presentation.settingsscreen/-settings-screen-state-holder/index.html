class SettingsScreenStateHolder(settingsInteractor: SettingsInteractor, scope: CoroutineScope)

State Holder экрана настроек.

Отвечает за подготовку реактивного состояния экрана SettingsScreenState, объединяя сохранённые настройки из SettingsInteractor и редактируемый черновик. Формирует поток команд commands для навигации и других действий, инициируемых UI. Использует SettingsRepository.default для определения момента первого применения настроек к черновику (если черновик ещё не изменялся пользователем, он инициализируется из сохранённых значений).
