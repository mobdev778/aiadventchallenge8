DTO-перечисление, представляющее уровень усилий, затрачиваемых моделью на рассуждение (reasoning effort). Используется в запросах к API чат-клиента для управления глубиной логического анализа ответа.

Сериализуется в JSON с помощью SerialName в строковые значения: "low", "medium" и "high".
