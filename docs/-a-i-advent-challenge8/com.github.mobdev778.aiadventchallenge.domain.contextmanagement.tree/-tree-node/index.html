TreeNode

class TreeNode(val value: ChatMessage)

Узел бинарного дерева диалога, представляющий собой одно сообщение чата.

Используется для построения древовидной структуры диалоговых веток. Каждый узел хранит ссылку на модель ChatMessage и может иметь до двух дочерних узлов: левого и правого. Левое поддерево соответствует первой альтернативной ветке, правое — второй. Структура позволяет переключаться между вариантами продолжения диалога (см. ChatMessage.branchB), а также обеспечивает эффективный обход и поиск сообщений в контексте управления диалоговым деревом.
