ProfileListScreenStateHolder

class ProfileListScreenStateHolder(profileRepository: ProfileRepository, scope: CoroutineScope)

Компонент-держатель состояния экрана списка профилей.

Отвечает за предоставление UI-слою актуального списка профилей через profiles, за обработку событий экрана (см. ProfileListScreenEvent) и формирование команд навигации/действий через commands.

Является синглтоном в DI-контейнере Koin и оперирует корутинами в рамках переданного scope (обычно с привязкой к жизненному циклу экрана).
