SystemPromptBuilder

class SystemPromptBuilder

Строитель системного промпта (SystemPromptBuilder), использующий шаблон "строитель" (Builder) с плавным интерфейсом для пошагового формирования текстового промпта, отправляемого агенту.

Промпт агрегирует информацию из контекста задачи (TaskContext), активного профиля (Profile), бизнес-инвариантов (Invariant) и правил поведения агента. Используется для подготовки инструкции LLM к очередному шагу решения задачи.
