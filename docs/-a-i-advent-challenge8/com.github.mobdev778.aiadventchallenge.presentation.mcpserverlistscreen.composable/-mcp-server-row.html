McpServerRow

@Composable
fun McpServerRow(server: McpServer, onCheckedChange: (Boolean) -> Unit, onClick: () -> Unit, onDeleteClick: () -> Unit)

Composable-элемент строки списка для отображения одного сервера MCP.

Отображает чекбокс активности, имя сервера, его URL (сокращённый при необходимости) и кнопку «Удалить». Локальные серверы имеют ограниченную возможность изменения состояния чекбокса и не могут быть удалены.

Parameters

server

Модель сервера MCP, данные которой отображаются в строке.

onCheckedChange

Колбэк, вызываемый при изменении состояния чекбокса активности. Принимает новое булево значение.

onClick

Колбэк, вызываемый при клике на строку (исключая чекбокс и кнопку).

onDeleteClick

Колбэк, вызываемый при нажатии кнопки удаления.
