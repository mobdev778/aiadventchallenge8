ChatScreenEvent

sealed interface ChatScreenEvent

События экрана чата, описывающие все возможные действия пользователя.

Используется для однонаправленной передачи намерений от UI-слоя к ViewModel, что позволяет централизованно обрабатывать пользовательский ввод и изменять состояние экрана.

Каждое событие представляет собой атомарное действие: навигацию, ввод текста, управление сообщениями (раскрытие веток, клик по сообщению) и т.д.
