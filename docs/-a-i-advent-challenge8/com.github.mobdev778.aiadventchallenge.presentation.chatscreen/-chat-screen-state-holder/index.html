ChatScreenStateHolder

class ChatScreenStateHolder(chatInteractor: ChatInteractor, settingsInteractor: SettingsInteractor, taskContextRepository: TaskContextRepository, scope: CoroutineScope)

Основной держатель состояния экрана чата (ChatScreen).

Выполняет роль ViewModel: управляет состоянием экрана, преобразуя потоки данных от доменных интеракторов (ChatInteractor, SettingsInteractor) и репозитория контекста задач (TaskContextRepository) в готовое UI-состояние ChatScreenState. Отвечает за построение древовидной структуры сообщений (ChatUiMessage) с учётом ветвления, видимых окон и настроек управления контекстом.

Предоставляет:

  • uiState — реактивное состояние экрана, объединяющее чат, сообщения, ввод, контекст задачи, автопроигрывание и текущую стратегию управления контекстом;

  • commands — буферизованный поток одноразовых команд (ChatScreenCommand) для навигации и других действий, не фиксируемых в состоянии.

Зависимости внедряются через конструктор (DI). Основная работа происходит на Dispatchers.Default для снижения нагрузки на главный поток.
