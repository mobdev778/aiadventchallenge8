interface RagDocumentDao

Интерфейс доступа к данным (DAO) для сущностей RAG-системы.

Предоставляет методы для наблюдения, вставки и удаления документов (RagDocumentEntity), их фрагментов (RagDocumentChunkEntity), а также управления конфигурацией (RagConfigEntity). Все операции выполняются асинхронно (suspend или Flow) в контексте базы данных Room.
