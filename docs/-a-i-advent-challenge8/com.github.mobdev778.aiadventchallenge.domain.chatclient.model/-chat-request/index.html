ChatRequest

data class ChatRequest(val model: String, val reasoningEffort: ReasoningEffort? = null, val messages: List<Message>, val temperature: Double = 0.7, val tools: List<Tool> = emptyList())

Запрос к языковой модели, инкапсулирующий все параметры вызова.

Этот data-класс используется для формирования запроса в чат-клиенте, агрегируя идентификатор модели, уровень усилий рассуждения (см. ReasoningEffort), историю сообщений (Message), температуру генерации и список доступных инструментов.

Parameters

model

Идентификатор модели, которую необходимо использовать.

reasoningEffort

Уровень усилий, прилагаемых моделью для выполнения рассуждений. Может быть null – тогда используется значение по умолчанию.

messages

История диалога в виде списка сообщений Message.

temperature

Температура генерации (степень случайности ответов). По умолчанию 0.7.

tools

Список инструментов (Tool), доступных модели. По умолчанию пустой.
