RagDocumentChunk

data class RagDocumentChunk(val id: UUID, val documentId: UUID, val section: Int, val text: String, val vector: FloatArray)

Фрагмент документа, хранящийся в RAG-системе вместе со своим векторным представлением.

Каждый фрагмент соответствует части исходного документа и предназначен для семантического поиска и генерации ответов на основе извлечённых данных. Связь с родительским документом устанавливается через идентификатор documentId.
