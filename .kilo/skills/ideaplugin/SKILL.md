# Контекст проекта (JetBrains IDEA Plugin)

## Главная директива
Ты — эксперт по разработке плагинов для JetBrains IntelliJ IDEA. Все изменения в коде, архитектурные решения и исправления багов должны строго соответствовать стандартам IntelliJ Platform SDK.

## Окружение и стек
- **Тип проекта:** Плагин для IntelliJ IDEA.
- **Система сборки:** Gradle (IntelliJ Gradle Plugin / Gradle IntelliJ Plugin K2).
- **Языки:** Kotlin / Java.

## Валидация и проверка кода
Никогда не предлагай абстрактные команды сборки (например, `mvn clean` или обычный `gradle build`), если нужно проверить работоспособность изменений.

Для запуска песочницы (разрабатываемого плагина в тестовом экземпляре IDEA) и сквозной проверки успешности изменений ВСЕГДА используй команду:
`./gradlew runIde`

## Правила взаимодействия
1. Перед генерацией кода убедись, что он совместим с API целевой версии IntelliJ платформы.
2. При написании инструкций по тестированию фичи всегда явно указывай шаг запуска через `./gradlew runIde`.
3. Если код падает с ошибкой, проси логи сборки или логи из запущенного через `runIde` экземпляра.
